Quick visual guide

6 checkpoints

Not an administrator? Stop and ask the device owner or IT team.

⌕

1. Find the app

Right-click its shortcut → Open file location.

.EXE

2. Confirm the file

Show file extensions. Check you have the correct .exe.

⚙

3. Open Security

Right-click .exe → Properties → Security.

▤

4. Record permissions

Take a screenshot before changing any settings.

✓

5. Test carefully

Proceed only with approval. Never add Everyone automatically. Apply the approved test change and try opening the app.

↶

6. Restore changes

Remove only the Deny entries you added, then test again.

This method may not block every part of packaged apps or apps with multiple executable files.

↶ Undo the restriction

Properties → Security → Edit. Remove only the Deny entries you added, select Apply, and test the app. Unsure? Stop and ask an administrator.

Quick definitions

Glossary

Administrator

A Windows account allowed to perform certain system tasks.

Executable file (.exe)

A file Windows can run as a program.

File extension

Ending of a filename, such as .exe, that indicates file type.

File permissions

Settings that control what a user or group can do with a file.

Everyone group

A Windows group whose permissions may affect many users.

Read & execute

Permission to read a file and run its executable content.

Deny entry

A permission rule that explicitly blocks an action.

File Explorer

Windows tool for browsing folders and files.
